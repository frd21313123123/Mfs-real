# Локальный API v1

База: `http://127.0.0.1:8147/api/v1`. Интерфейсы Windows/flyPad/Fenix companion используют один сервис и типы `src/client.ts`. Все расчётные поля прототипа явно пусты. Никаких запросов к SimBrief или MCDU нет.

| Метод и путь | Запрос | Ответ |
|---|---|---|
| GET `/status` | — | `apiVersion: "1"`, `worldRoutingReady: false`, число ICAO-аэропортов, доступность PDF, источники, неподтверждённая Fenix cockpit integration |
| GET `/aircraft` | — | Шесть профилей с `status: "unverified"`, `accuracyPercent: null`, источниками и пропусками |
| GET `/airports?q=...` | 2–80 символов | До 20 записей справочника: ICAO, имя, страна, координаты |
| POST `/probes` | JSON `{departure, arrival, aircraft}` | Проверка двух аэропортов, профиль, null-расчёты, предупреждения и необязательный тестовый PDF |
| POST `/flights` | Пока контракт не активирован | Всегда 503 `FEASIBILITY_GATE_CLOSED` |
| GET `/documents` | — | Метаданные сохранённых PDF |
| POST `/documents?icao=UUEE&label=chart.pdf` | Сырые байты PDF, максимум 20 МиБ | 201, ID документа, число страниц, относительные `pdfUrl`/`pageUrls` |
| GET `/documents/{uuid}/document.pdf` | — | Исходный PDF |
| GET `/documents/{uuid}/page-1.png` | — | Отрендеренная страница |

Пример проверки интеграции:

```json
{"departure":"UUEE","arrival":"ULLI","aircraft":"fbw-a32nx"}
```

В ответе: `status: "integration-probe"`, `route`, `alternate`, `fuel`, `duration`, `mass` равны `null`. Предупреждения: `INTEGRATION_TEST_ONLY`, `GLOBAL_PROCEDURES_NOT_CONFIRMED`, `PERFORMANCE_NOT_VALIDATED`, `RAD_NOTAM_NOT_CHECKED`. Документ проверяет генерацию и просмотр; он не OFP с расчётными данными.

ICAO нормализуется trim/uppercase и должен состоять из четырёх латинских букв; аэропорты различаются, профиль должен быть известен. JSON ограничен 8 КиБ. Ошибки: 400 неверный ввод, 404 неизвестный аэропорт/ресурс, 413 размер, 422 нечитаемый PDF, 429 заняты PDF-workers, 503 недоступный набор/рендер/закрытый расчёт. PDF: 1–50 страниц, без пароля; максимальный размер страницы и растровой картинки ограничен.

Сервис не имеет LAN binding, авторизации аккаунтов или автоматического открытия портов. Разрешены только заданные local/Coherent origins и local Host. Прототип допускает `null` origin для проверки Coherent; это не готовая модель безопасности удалённого сервиса. API не позволяет задавать произвольные filesystem paths. Загрузка документов выполняется локально, до двух параллельных рендеров, таймаут процесса 45 секунд.

Версия `/v1` закрепляет исследовательские ответы. Когда полноценный planner станет доступен, его семантику, источники, циклы, ограничения и единицы нужно согласовать отдельным контрактом; нельзя превратить `/probes` в расчёт незаметно для клиента.
