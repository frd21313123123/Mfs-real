# Источники и лицензии

Собственный код Fly-calc предоставляется по GPL-3.0-or-later. Полный текст — `LICENSE`. Это не меняет условия исходных данных или аддонов. Проект не связан с FlyByWire, Fenix, PMDG, ToLiss, Zibo, FAA и поставщиками навигационных данных.

| Материал | Подтверждённое условие | Использование здесь |
|---|---|---|
| [FlyByWire aircraft](https://github.com/flybywiresim/aircraft) | GPL v3; исходные copyright сохранены в патчах | Отдельные исходные снимки и патчи EFB. Сам самолёт не распространяется |
| [FlightGear fgdata](https://gitlab.com/flightgear/fgdata) | В заголовках `fix.dat.gz`, `nav.dat.gz`, `awy.dat.gz` явно указана GPL-2.0-or-later для данных | Локальная инвентаризация. Raw-файлы исключены из git. При распространении сохранить исходники данных, уведомления и применимую лицензию |
| [OurAirports](https://ourairports.com/data/) | Public domain, отдельное заявление для данных | Локальный справочник аэропортов и аудит CSV. Дата снимка отображается |
| [FAA CIFP](https://www.faa.gov/air_traffic/flight_info/aeronav/digital_products/cifp/) | В архивном `FAA CIFP Disclaimer.pdf` указано отсутствие copyright по Title 17 U.S.C.; действуют Customer Agreement for Error Notification и обязательные disclaimers для производных продуктов | Инвентаризация архива 2609, без публикации производного навигационного продукта. Текст disclaimer остаётся в исходном архиве |
| [openAIP API](https://api.core.openaip.net/api/system/specs/v1/schema.json) | Метаданные API указывают CC BY-NC 4.0 | Только исследована схема. База не скачана и не включена; перед подключением проверить условия самого экспорта и атрибуцию |
| React, TypeScript, esbuild, Electron | Собственные лицензии npm-пакетов | См. `node_modules/*/LICENSE*` и `package-lock.json`. При выпуске desktop-сборки включить лицензии runtime и зависимостей |
| ReportLab, PDFium/pypdfium2 | Собственные лицензии Python-пакетов | Генерация тестового PDF и рендер пользовательских документов. При упаковке добавить уведомления библиотек |

Владение аддоном или возможность прочитать его файлы не подтверждают разрешение перераспространять модель характеристик. Публичные руководства используются как справочные источники; защищённые таблицы, бинарные файлы аддонов и коммерческие базы в проект не включены.

Национальные AIP и чарты имеют собственные условия. Свободный просмотр PDF не равен разрешению массовой загрузки, локального кэширования или извлечения навигационной базы. Пользовательские PDF обрабатываются локально. Австралийские AIP автоматически не загружаются из-за ограничений опубликованных условий просмотра.
