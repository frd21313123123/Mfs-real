# Fly-calc · исследовательский прототип

Реализован локальный технический прототип: Windows-интерфейс, сервис с API v1, проверка двух ICAO, выбор шести аддонов и просмотр PDF как изображений страниц. Подготовлены исходные патчи вкладки flyPad для **двух отдельных ревизий** A32NX. Есть браузерный режим для экрана Fenix; установка вкладки в штатный планшет Fenix пока не подтверждена.

**Полноценный расчёт закрыт.** Бесплатная мировая база SID/STAR/заходов не подтверждена, профили самолётов не калиброваны. Маршрут, запасной, массы, время и топливо возвращаются как `null`. Тестовый PDF проверяет связь и отображение; это не расчётный OFP. Собственные маршруты SimBrief не используются.

## Запуск на этом компьютере

В PowerShell из этой папки:

```powershell
npm run build
npm start
```

Откройте `http://127.0.0.1:8147`. Режим Fenix: `http://127.0.0.1:8147/fenix`. Проверка компоновки flyPad: `http://127.0.0.1:8147/?display=flypad`.

Для отдельного Windows-окна используйте **Start-FlyCalc.cmd** или `npm run desktop`. Требуется установленный runtime Electron; если стандартный загрузчик npm зависает, выполните `python scripts/install_electron.py`. Этот запасной загрузчик берёт официальный Windows x64 архив Electron и проверяет SHA-256 из закреплённого npm-пакета.

Нажмите «Проверить рейс», затем «Открыть тестовый документ». В разделе «Документы» можно добавить собственный PDF и связать его с ICAO вылета, назначения или будущего запасного. Сервис хранит оригинал и PNG-страницы в `output/documents`. Разрешённый размер: 20 МиБ, 1–50 страниц. Чарты автоматически с сайтов не скачиваются.

## Установка в новом каталоге

Нужны Node.js **24.13.0 или новее**, Python 3.12+ и Windows x64 для запасного установщика Electron. SQLite использует встроенный модуль Node; Python для базы обходится стандартной библиотекой. Для PDF нужны `reportlab` и `pypdfium2`.

```powershell
npm ci
python -m pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File scripts/configure_runtime.ps1
python scripts/collect_sources.py --group all
python scripts/collect_sources.py --group supplement
python scripts/audit_data.py
npm run build
```

Загрузки публичных наборов автоматизированы, ручной импорт CSV не требуется. Исследовательские файлы сохраняются отдельно и не объединяются в пригодную для маршрутизации навигационную базу. Подготовленный индекс аэропортов — `data/research.sqlite`. Скрипт конфигурации выбирает Python из среды Codex, если он доступен, иначе системный Python; пути сохраняются локально в `.local/runtime.json`.

Источники и условия использования: [отчёт](docs/feasibility.md), [уведомления о сторонних материалах](THIRD_PARTY.md). Для FAA CIFP действуют соглашение об уведомлении об ошибках и собственные disclaimers FAA. Непроверенные связи процедур не считаются установленными ошибками источника.

## Проверки

```powershell
npm test
python -m unittest discover -s tests -p "test_*.py"
npm run check
```

`npm run check` проверяет синтаксис, строгий TypeScript и применимость патчей к скачанным исходным снимкам FBW. Это **не полная сборка A32NX**. Для браузерного сценария есть `node scripts/ui_check.mjs`: он использует Playwright из среды Codex и установленный Edge; можно задать `PLAYWRIGHT_MODULES` и `FLYCALC_BROWSER`.
