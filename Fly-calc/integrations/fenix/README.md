# Отображение для Fenix A320

Реализован общий интерфейс Fly-calc в режиме `http://127.0.0.1:8147/fenix`: увеличенные элементы управления, просмотр PDF-страниц, ввод ICAO, выбор самолётов, запросы к тому же локальному API. Проверена браузерная компоновка 2028×1536 и компактный экран. Это **сопутствующий интерфейс**, а не установленная вкладка в кабине Fenix.

[Официальная инструкция Fenix](https://support.fenixsim.com/hc/en-us/articles/12458461738255-How-to-change-the-EFB-background-image-and-access-the-WEB-MCDU) описывает внешнюю web-версию EFB на `localhost:8083` и размеры фонового изображения 2028×1536. Размер фонового изображения использован как один из тестовых размеров; он не доказывает точный viewport планшета. Доступ к web-EFB не даёт документированного способа добавить туда собственное приложение.

[Официальная интеграция с SimBrief](https://support.fenixsim.com/hc/en-us/articles/12459075051791-How-to-use-FenixSim-s-Simbrief-integration) относится к загрузке данных SimBrief. Она не подтверждает возможность подключить собственный сервер OFP или заменить страницу планшета на произвольный URL.

На 09.10.2026 в проверенных официальных материалах не найден публичный SDK регистрации сторонних вкладок. Это результат доступного исследования, а не утверждение об отсутствии внутренних или партнёрских интерфейсов Fenix. Установка Fenix на этом компьютере не обнаружена в проверенных стандартных каталогах; проверка в кабине не выполнена.

Для завершения встроенного отображения нужны документированный SDK либо подтверждённый производителем способ открытия локальной страницы в штатном EFB, точная версия Fenix и проверка в MSFS 2020/2024. Требуется проверить сетевые запросы к `127.0.0.1:8147`, изображения PDF, управление мышью/касанием, перезапуск сервиса и сохранность штатных функций EFB. Без этого нельзя обещать установочный пакет нативной вкладки.

Порт Fly-calc — **8147**, штатного Fenix web-EFB — **8083**. Сервис Fly-calc не занимает порт Fenix. Подмена API SimBrief и модификация закрытых бинарных файлов не реализованы. Обращения производителю от имени пользователя не отправлялись.
